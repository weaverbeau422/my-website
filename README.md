# Forge — Workout Tracker

A sleek, client-side workout tracker built with HTML, CSS and JavaScript.

## Features
- Dashboard with weekly workouts, total sets, volume and exercise PRs
- Workout logging with exercise, weight, reps and optional RPE
- Workout history with search and delete
- Exercise library with custom exercises
- Built-in rest timer
- Local browser storage (no account/backend required)
- JSON export/import backups
- Responsive mobile layout

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to your GitHub repository and enable:
Settings → Pages → Deploy from a branch → main → /(root)

Note: the Google Fonts import requires internet access. The site otherwise works client-side.
